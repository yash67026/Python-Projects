# deepFake
# Deepfake Detection using Python

## Overview

This project is a Python-based Deepfake Detection system that identifies whether an image or video is authentic or AI-generated. It leverages computer vision and machine learning techniques to analyze media content and detect signs of manipulation.

## Features

* Detects deepfake images/videos
* Fast and efficient processing
* Easy-to-use Python implementation
* Modular and customizable code
* Suitable for research and educational purposes

## Technologies Used

* Python 3
* OpenCV
* NumPy
* TensorFlow/Keras
* Scikit-learn
* Matplotlib

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yash67026/Deepfake-Detection.git
   ```
2. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:

   ```bash
   python main.py
   ```

* Digital Forensics

* Fake News Detection
